02 Personal project

SmartFridge

Shared food inventory Web application

Context

Sharing a kitchen means keeping track of more than just what’s in the fridge. I built SmartFridge for a shared student apartment, where groceries belong to different people and can easily be forgotten.

Implementation

The app tracks products, ownership and expiry dates across the fridge, freezer and pantry. EAN barcode scanning helps with adding products, while a shopping list keeps the next grocery run organised.

03 University project

SkiLog

GPS ski tracking Android / Kotlin

Context

A day of skiing includes both downhill runs and time spent getting back up the mountain. SkiLog records the activity using GPS and separates those parts automatically.

Implementation

I developed the native Android app in Kotlin, including automatic classification of downhill and uphill or lift segments. A route map and per-segment statistics show distance, speed and time alongside an activity overview.
